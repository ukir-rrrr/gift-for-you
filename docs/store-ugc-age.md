# UGC 要件と年齢区分の方針（F3-12）

**ドラフト。** App Store Review Guidelines 1.2（ユーザー生成コンテンツ）と Google Play の UGC ポリシーに沿って、実装済みの対策を整理したもの。

## UGC 対策（実装との対応）

| 要件 | 実装 |
| --- | --- |
| 不適切な内容のフィルタ | 公開前に全写真を Cloud Vision SafeSearch で判定（不可なら公開できない、判定できないときも承認しない）。文章は語句リスト。サーバー側で再判定するので、改造クライアントでも回避できない。 |
| 通報の仕組み | ギフトの画面（タイトル・手紙）から「通報・ブロック」。理由5種。異なる通報者3人で自動仮非公開。管理画面で確認し、非公開・削除・公開に戻すを選ぶ。 |
| 利用者のブロック | 受け取る人が送り主をブロック。以後そのブラウザではその送り主（アカウント単位、未連携なら端末単位）のギフトが開かない。 |
| 連絡先の公開 | サポートページ（`/support`）にメールアドレス、作成アプリのホームとアカウント画面、受け取る人のギフト画面（タイトル・手紙・エラー）からリンク。 |
| 写っている本人の削除依頼 | `/legal/removal`、受付時点で仮非公開。 |
| 迅速な対応 | 管理画面に未対応の通報・削除依頼を一覧。**運用目標（要決定）：24時間以内に確認。** |
| 利用規約での禁止事項 | `/legal/terms` 第4条（ドラフト）。 |

ギフトは公開のフィードやランキングを持たず、リンクを知っている人だけが開ける 1対1 の贈り物。見知らぬ利用者同士が出会う機能はない（ありがとうスタンプは定型文のみで、自由入力はない）。

## 年齢区分の方針

- **対象年齢：13歳以上**（規約に明記）。子ども向けカテゴリには出さない。
- App Store の年齢区分アンケート：暴力・性的表現・ギャンブルなどの項目は「なし」。**「ユーザー生成コンテンツ」「メッセージング」に該当あり**として回答する（贈る人が写真と文章を入れるため）。結果は 12+ または 13+ になる想定。
- Google Play（IARC）：「ユーザー同士のやりとり」あり、「ユーザー生成コンテンツの共有」あり。デジタル購入あり。
- アプリ内課金があるため、未成年の購入は保護者の同意を前提とする旨を規約に記載済み。
- 方針の最終判断（13+ にするか 17+ に寄せるか）は、モデレーションの精度と運用体制を見て riku が決める。
